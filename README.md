## 🤖 自动化更新方式

本页面内置了结构化的 AI 更新指令。在未来的任意时间节点，只需将页面底部的 **「AI 自动化更新提示词」** 发送给任意 AI Coding Agent（如 Claude, Cursor, Antigravity 等），由 Agent 在具备 GitHub 访问权限时重新收集数据、核对统计口径并更新本报告。页面自身不会定时抓取或自动刷新。
